# ProjectReviewer - 代码驱动型智能模拟面试官 🎯

[![TypeScript](https://img.shields.io/badge/TypeScript-ES2022-blue.svg)](https://www.typescriptlang.org/)
[![Node.js](https://img.shields.io/badge/Node.js-24%2B-green.svg)](https://nodejs.org/)
[![Test Status](https://img.shields.io/badge/tests-15%20passed%2C%200%20failed-brightgreen.svg)]()

> **专为技术求职者量身打造的模拟面试 Agent**。通过直接解析你的本地工程代码或 GitHub 公开仓库，化身为严苛、专业的资深技术面试官，以**“一对一、一来一回”**的递进式深挖机制模拟实战对练，考后自动生成含**“大厂标杆范例参考回答”**的四维复盘诊断报告。

---

## 🌟 核心特性

- 🔍 **多源代码特征感知**：支持指定本地工程绝对/相对路径或 GitHub 公开仓库 URL，两阶段轻重结合扫描，自动过滤 `.git`、`node_modules` 等冗余目录。
- 🤝 **严格单步交互 (Turn-by-turn)**：绝对的一来一回单题对话，杜绝一次性多题轰炸。
- ⚡ **自适应深度追问 (Follow-up)**：根据作答中的技术选型（如缓存、锁、队列、异步等），自动展开 1~2 层并发一致性、极端容灾与边界防御深挖。
- 💡 **大厂高分标杆回答 (Best Practice)**：复盘报告中不仅包含失分点诊断，更为每个考点提供大厂架构师标准示范答题框架。
- 📊 **四维加权打分模型**：技术深度 (40%) + 架构权衡 (30%) + 容灾工程 (20%) + 表达逻辑 (10%)，输出 S/A/B/C 专业评级。
- 📁 **集中式报告归档**：不污染被测代码库，所有复盘统一归档于 `./interview-records/<被面试项目名>/` 目录，便于求职者多轮对比复习。
- 🔄 **多轮进阶演练**：支持 `--retry`（锁定失分弱项强化重练）与 `--next`（抽取全新考点开启新一轮面试）。

## 🚀 快速上手

### 1. 运行环境要求
- **Node.js**: v22.6+ 或 v24+（原生支持 TypeScript 运行时，零外部构建打包开箱即用）。

### 2. 启动面试
在终端中进入项目目录，执行：

```bash
# 面试本地项目（如当前工作区下的 AgentRelay 或其他工程）
node src/cli.ts ../AgentRelay

# 面试 GitHub 公开仓库
node src/cli.ts https://github.com/facebook/react

# 选用全面考察模式 (综合技术+八股+场景)
node src/cli.ts ../AgentRelay --mode comprehensive

# 针对上一轮薄弱点进行原题重练强化
node src/cli.ts ../AgentRelay --retry

# 换一批全新考点进行进阶第二轮面试
node src/cli.ts ../AgentRelay --next
```

## 🎮 面试交互指令

| 指令 | 说明 |
| :--- | :--- |
| `直接输入回答内容` | 提交当前问题的解答，面试官将视回答自适应追问或切入下一题 |
| `跳过` / `不会` / `pass` | 跳过当前考点，记为未掌握并平滑过渡到下一个主考点 |
| `/exit` 或 `/quit` | 中途提前退出。若已作答 $\ge 2$ 题，可选择生成阶段性复盘报告 |

## 📄 复盘报告展示示例

面试结束后，控制台将输出精简卡片，并在 `./interview-records/<项目名>/` 自动生成 Markdown 报告文件：

```

================================================================================
【综合得分】：86 分  |  评级：[A 级: 建议通过 / Offer]
【面试时间】：2026-11-03 18:10:00   |  模式：技术深度与架构师型

【四维战力评估】：
  - 技术深度与底层原理: 88 / 100 (权重 40%)
  - 架构设计与方案权衡: 85 / 100 (权重 30%)
  - 工程边界与容灾防范: 82 / 100 (权重 20%)

【面试官总评】：
  本次面试综合得分 86 分（A 级）。候选人对 AgentRelay 的业务流转与核心技术栈有非常扎实的实战掌控力，面对多轮深挖追问能给出逻辑自洽的方案。整体表现良好，建议通过。

【大厂标杆回答与复盘报告已归档】：
  📄 文件位置: ./interview-records/AgentRelay/interview-review-AgentRelay-20261103181000.md
================================================================================
```

## 🏗️ 单项目标准目录规范

项目库中每个独立项目推荐采用如下结构：

```text
projects/<项目英文名>/
├── README.md               # 项目概览、背景与快速启动指南
├── docs/                   # 项目专属文档体系
│   ├── prd/                # 产品需求文档 (PRD)
│   ├── trd/                # 技术设计方案 (TRD)
│   └── architecture/       # 架构图、数据字典、接口文档
└── src/                    # 项目源代码 / 原型代码
```

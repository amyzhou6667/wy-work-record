## 🏗️ 单项目标准目录规范

项目库中每个独立项目推荐采用如下结构：

```text
projects/<项目英文名>/
├── README.md               # 项目概览、背景与快速启动指南
├── docs/                   # 项目专属文档体系
│   ├── prd/                # 产品需求文档 (PRD)
│   ├── trd/                # 技术设计方案 (TRD)
│   └── architecture/       # 架构图、数据字典、接口文档
└── src/                    # 项目源代码 / 原型代码
```

## ⚙️ 项目通用技术栈与架构标准

1. **强类型规约**：凡属于 JS/TS 生态的服务端、CLI、工具脚本与测试用例，**强制固定为 TypeScript (`.ts`)**，配置标准 `tsconfig.json`。
2. **前端框架规约**：凡涉及 Web/H5/移动端/可视化 UI 的页面，**强制采用 Vue 3 或 React 实现组件化与状态驱动（结合 TypeScript，即 `.vue` + TS 或 `.tsx`）**，严禁使用原生 HTML + 原生 DOM 操控编写前端，杜绝项目退化。
3. **离线高可用保障**：前端方案必须具备内网与离线免依赖运行能力（配备本地 vendor 或轻量开箱即用打包）。

# OpenDeck 项目全景解析与简历 STAR 提炼指南

---

## 📌 一、项目基本档案

| 维度 | 详情 |
| :--- | :--- |
| **项目名称** | **OpenDeck** (`open-deck`) |
| **业务定位** | 面向 OpenClaw 等自主智能体（Autonomous Agents）的轻量级任务执行可视化仪表盘与产物管控平台 |
| **工程架构** | pnpm Monorepo 多包工程架构（前端应用 + 后端服务一体化协同） |
| **核心技术栈** | **前端**：Vue 3.5 + TypeScript (TSX/JSX) + Vite + Element Plus + Tailwind CSS + Vue Router + Vitest + Playwright<br>**后端**：NestJS 11 + TypeScript + Express + RxJS + Swagger + Serve-Static |
| **核心模块** | 1. **Tasks 模块**：任务执行链路状态观测、时间线跟踪、树状子任务拓扑还原与敏感数据过滤<br>2. **Files 模块**：Agent 自动生成资产文件自动嗅探、任务产物关联映射、在线预览与流式下载<br>3. **Skills 模块**：技能注册表、调用历史元数据、执行参数与上下文追踪 |

---

## 🏗️ 二、核心架构与技术亮点

1. **轻量非侵入式 Agent 观测链路**：
   - 无需侵入修改 OpenClaw 核心调度器逻辑，通过读取并逆向解析 OpenClaw 会话日志（Session Logs）与产物存储目录，动态还原 Agent 思考、工具调用与子任务执行链路。
2. **多层脱敏与安全防御引擎**：
   - 针对 API Key、Token、Secret 等高危凭据设计基于正则与对象深层遍历的递归脱敏过滤器（`redactUnknown`），防止大模型执行日志泄漏敏感环境信息。
3. **Monorepo 一体化工程保障**：
   - 基于 pnpm Workspace 建立全栈工程约束，整合 husky + lint-staged、commitlint，并落地单元测试（Vitest / Jest）与端到端自动化测试（Playwright），构建 0 缺陷门禁体系。

## 📝 三、简历项目经验提炼（STAR 原则范例）

### 🌟 版本 A：资深全栈研发工程师视角 (Senior Fullstack Engineer)

> **项目名称**：OpenDeck —— 自主智能体可视化任务管控与产物分析平台  
> **核心技术**：Vue 3、TypeScript、TSX、NestJS、Vite、Tailwind CSS、RxJS、Vitest、Playwright  
> **项目描述**：  
> 针对大模型 Agent 在多任务并发执行中“上下文黑盒难以追溯、任务产生的大量碎片文件检索困难、Token 消耗不透明”的痛点，主导开发了轻量级 Agent 任务可视化仪表盘平台，实现任务执行流、生成文件与技能调用的透明化观测。  
> **职责与行动 (STAR - Action)**：  
> - **架构设计**：采用 pnpm Monorepo 搭建全栈架构，基于 NestJS 11 构建解耦的领域服务，前端基于 Vue 3 + TSX 实现高性能动态数据看板与组件化开发。  
> - **会话还原与拓扑重组**：设计基于 Session 日志的流式解析算法，逆向提取 Agent 思考、工具执行与子任务状态，重构出树状任务执行时间线，支持多级父子任务溯源。  
> - **安全与脱敏体系**：针对大模型工作区敏感凭据风险，构建深度递归脱敏中间件，拦截过滤 API Key、Bearer Token 等 10+ 类敏感模式，杜绝日志数据二次外泄。  
> - **产物关联与资源管理**：设计任务-文件动态映射机制，结合文件系统元数据嗅探，实现百毫秒级多文件聚合关联，提供多格式文档即时预览与流式打包下载。  
> - **工程化与质量门禁**：搭建覆盖 Unit/E2E 的自动化测试流水线（Vitest + Playwright），集成 Git 提交前检查，测试覆盖核心解析链路达 90%+。  
> **业务成果 (STAR - Result)**：  
> 显著降低智能体执行排障耗时达 60%，单次任务产物检索效率提升 3 倍以上，被作为标准可视化工具配套推广应用。
